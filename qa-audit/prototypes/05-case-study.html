How we built Aura One

A scroll-driven product page for a fictional over-ear headphone: a compressed 3D model, scroll choreography tied to one timeline, and a budget that holds on a phone.

Process

Three steps, from CAD file to scroll.

01 — Model

Compress the model

Clean the mesh, bake the materials into a small set of textures, and compress the geometry before it ever reaches the browser.

02 — Motion

Choreograph the scroll

One scroll progress value drives the camera, the exploded view and the text. Springs keep the motion settled when the user stops.

03 — Budget

Hold the budget

Set a frame-time budget per device class, measure it on real phones, and fall back to a lighter render when the budget slips.
